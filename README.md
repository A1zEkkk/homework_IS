# Лабораторная работа: PCA + kNN на MNIST

Откройте `.ipynb` в Jupyter или PyCharm и запускайте ячейки сверху вниз (`Shift+Enter`). В ноутбуке сохранены результаты выполнения, графики, ответы на вопросы и выводы.

## Зависимости

```powershell
python -m pip install -r requirements.txt
```

Используются библиотеки из задания: NumPy, Matplotlib, scikit-learn и Seaborn. PCA и kNN реализованы самостоятельно; готовые реализации scikit-learn нужны для сравнения, а Seaborn — для тепловой карты.

Функция `load_mnist()` определена прямо в первой ячейке ноутбука. Она скачивает исходные IDX-файлы MNIST в `data/mnist` средствами стандартной библиотеки Python. Устанавливать пакет `mnist` не требуется. Уже скачанные данные используются повторно без интернета. Файл `mnist.py` содержит отдельную копию загрузчика, но ноутбук от него не зависит.

## Эксперимент

После объединения обучающей и валидационной частей из 60000 изображений выбираются 5000 случайных объектов с фиксированным seed=42. Уменьшение выборки разрешено в советах задания и ускоряет собственный kNN. Для экспериментов используется стратифицированное разбиение 70/30. PCA для классификации обучается только на тренировочной части. После подбора параметров модель проверяется на исходном независимом тесте MNIST из 10000 изображений.

Время kNN измеряется отдельно от PCA как медиана трёх запусков обучения и предсказания. Численные результаты относятся к указанной подвыборке; время зависит от компьютера.

Файлы `.bak` содержат исходный вариант лабораторной. `run_lab.py` позволяет повторно выполнить код и сохранить графики в ноутбуке без установки дополнительных библиотек Jupyter.
